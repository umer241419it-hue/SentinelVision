# Model Integrity — Coverage Statement & Security Guarantees (Stage 4 & Stage 5)

## 1. Detection Capabilities & Validated Coverage (Stage 4)

- **Detection Path**: White-box backdoor and trojan detection utilizing **Neural Cleanse** (trigger inversion optimization per class) combined with **Median Absolute Deviation (MAD)** anomaly index scoring, corroborated by **STRIP** (mask-preserving overlay variant) whenever MAD flags an anomalous class.
- **Corroboration Logic**: Step 6 scoring maps MAD anomaly index and STRIP entropy-suppression agreement into confidence, severity (`CRITICAL`, `LOW`), and disposition (`QUARANTINE`, `ACCEPT`).

---

## 2. Detection Limitations (Stage 4 Honest Reporting)

- **Dependent Corroboration**: STRIP runs as a corroboration detector on classes that Neural Cleanse + MAD has already flagged. If Neural Cleanse fails to identify an anomalous class (as observed in validated false-negative edge cases during calibration), STRIP does not independently scan the model.
- **Trigger Style Scope**: Validated exclusively against patch-style (BadNets / StaticTarget style) backdoor triggers on vision models. It has **NOT** been validated against non-patch triggers (blended, WaNet-style, or physical-world dynamic perturbations) or BackdoorBench suites.

---

## 3. Cryptographic Signing & Ledger Guarantees (Stage 5 Part B)

- **Finding Signing**: Findings generated by `model-integrity/src/finding_builder.py` are signed across all 8 canonical fields using the `ModelIntegrity` module Ed25519 private key.
- **Read-Time Integrity**: When queried through the Fabric Gateway bridge (`GET /findings/:id`), the signature is verified against `crypto-utils/public_key_registry.json`. Any out-of-band database tampering (e.g. altering disposition or severity directly in CouchDB) is detected immediately on read, setting `signatureStatus: "TAMPERED"`.
- **Legacy Limitation**: Findings committed prior to Stage 5 Part B lack a signature and evaluate to `signatureStatus: "UNSIGNED_LEGACY"`. They rely solely on Fabric block immutability and multi-org endorsement at write time.
